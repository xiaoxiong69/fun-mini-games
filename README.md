# 小小脑袋训练营 · 儿童认知游戏

面向 6 岁左右儿童的**家庭趣味认知游戏**，单文件 H5，双击即开，不需要服务器、不需要登录、断网也能玩。

> ⚠️ 本项目是亲子互动娱乐游戏，**不属于医疗康复手段，也不提供任何评估或诊断功能**。
> 如对孩子发育有疑问，请咨询儿科 / 发育行为科医生。

## 特点

- **单文件**：只有一个 `儿童前额叶训练.html`，HTML/CSS/JS 全在里面，约 100 KB
- **零依赖**：不联网、不加载任何外部资源，图形全部用 emoji，断网不裂图
- **本地存储**：所有记录存在浏览器 localStorage，不上传、不登录、不要手机号
- **儿童适配**：大按钮（≥48px）、点击缩放反馈、低饱和配色、无倒计时、无排名、无广告

## 怎么用

**电脑**：把 `儿童前额叶训练.html` 下载下来，双击用 Chrome / Edge 打开。

**手机 / 微信**：把文件发到微信（发给「文件传输助手」或自己）→ 点开 → 右上角「在浏览器打开」。

## 包含什么

每日训练共 6 个模块，顺序固定，模块之间强制休息 30 秒，全程约 25~32 分钟：

| 模块 | 训练方向 |
|---|---|
| 找不一样 | 选择性注意 |
| 听指令停一停 | 抑制控制（零失误过关） |
| 记住卡片 | 工作记忆（简单/一般/困难三档） |
| 换个玩法 | 任务切换 |
| 排排队 | 排序规划 |
| 猜猜心情 | 情绪觉察 |

另有 7 个可单独游玩的游戏（含数字舒尔特方格），以及：

- **星星本**：按日期记录每天的打卡与小结，只展示自己的进步，不做排名对比
- **家长设置**：算术验证后进入，可调难度、开关语音、解锁自由游戏、清空记录
- **防误触**：训练中长按左上角 3 秒才能退出，进度会自动保存

## 已知限制

1. 微信内置浏览器的语音合成（Web Speech API）存在偶发兼容问题，可能没声音；建议用系统浏览器打开
2. 清除浏览器缓存 / 换浏览器 / 无痕模式会丢失所有记录，且无法恢复
3. 本项目不引用网络图片，因此不存在图片过期问题

## 许可

仅供家庭自用。其中的 emoji 来自系统字体，不涉及第三方素材授权。
